Step 1 — Place Reference Object

Place a clearly visible object at a known distance to the left or right of the drone. Make sure it is visible in the camera feed. Point the camera forward (horizontally level).

  • Object should be at a measured distance (e.g. 200 cm)
  • Object should contrast clearly with the background
  • Keep drone stationary during calibration

Step 2 — Mark Object in Feed

Click on the center of the reference object in the camera preview below. The system will record the pixel position relative to the image center.
